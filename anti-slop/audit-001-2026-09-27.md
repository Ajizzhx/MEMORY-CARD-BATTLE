## Detailed Resolutions

### [F-001] R-32: Modal Escape Key Dismissal
- **Resolution:** Added `useEffect` listening for `e.key === 'Escape'` with proper event listener cleanup across all dismissible modal components:
  - `LeaderboardModal.jsx`
  - `CatalogModal.jsx`
  - `GuideModal.jsx`
  - `LogModal.jsx`
  - `PauseModal.jsx`
  - `ResetConfirmModal.jsx`
  - `CardDetailModal.jsx`

### [F-002] R-32: Card Grid Focus & Flip Operation
- **Resolution:** Updated `Card.jsx` with `role="button"`, `tabIndex={isFlipped || isMatched || isDisabled ? -1 : 0}`, dynamic `aria-label`, and `onKeyDown` handling `Enter` and `Space`. Added high-contrast `:focus-visible` ring in `Card.css`.

### [F-003] R-32: Global Visible Focus Indicators
- **Resolution:** Configured standardized `:focus-visible` outline (`2px solid var(--color-primary)`) with glowing cyan ring in `src/index.css`. Replaced `outline: none;` in `NameModal.css` with dedicated custom `:focus-visible` styling.

### [F-004] R-03: Mobile Touch Target Minimum 44px
- **Resolution:** Increased `.modal-close-icon-btn` dimensions to `min-width: 44px; min-height: 44px;` in `src/index.css`. Increased `.header-btn` in `GameBoard.css` to `min-height: 44px; padding: 8px 14px;`.

### [F-005] R-25: Color Contrast on Input Placeholder
- **Resolution:** In `src/components/NameModal/NameModal.css`, updated input placeholder color to `rgba(255, 255, 255, 0.65)`, surpassing WCAG AA standard (>5.5:1 ratio on `#050816` background).

### [F-006] R-27: Empty State in Filtered Catalog
- **Resolution:** Added `.catalog-empty-state` container and localized text key `catalogEmptyFilter` in `src/utils/i18n.js` and `CatalogModal.jsx` so users receive immediate, clear feedback when a filter returns zero active cards.

### [F-007] R-16: Copywriting AI Buzzwords
- **Resolution:** Replaced `"to empower your Deck:"` with concise, natural phrasing `"for your Deck:"` in `src/utils/i18n.js` (EN `lootSub`).

### [F-008] R-04: Cliché Decorative Emojis in Data States
- **Resolution:** Removed unnecessary rocket emoji (`🚀`) from empty state messages in `LeaderboardModal.jsx`, presenting a clean, typographic layout.

### [F-009] R-31: Code Comment Hygiene
- **Resolution:** Normalized decorative banner comments in `PlayerStatus.css` and verified code comments across the codebase to adhere to `antislop-code` guidelines without modifying logic or test assertions.
